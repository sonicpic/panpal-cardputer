# Code of Conduct

CardBridge contributors are expected to be respectful, specific, and
constructive. Harassment, discrimination, doxxing, threats, and deliberate
exposure of private credentials or user data are not acceptable.

Project maintainers may remove content or restrict participation when it is
necessary to keep the project safe and usable. Report serious or private
incidents through the security contact in [`SECURITY.md`](SECURITY.md).
