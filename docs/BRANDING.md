# PanPal 名称

公开产品名和仓库名使用 **PanPal**。项目支持 M5Stack Cardputer ADV 和 Windows
10/11。

项目简介：

> PanPal turns the M5Stack Cardputer ADV into a wireless microphone, keyboard,
> animated pet, and Codex task display for Windows.

当前 1.x 版本保留下面的技术标识，升级时可以沿用已有配置和配对数据：

- `CardBridge.exe`；
- `cardbridge` Python 包；
- `_cardbridge._tcp`、TCP 7788、UDP 7789；
- `%APPDATA%\CodexDeck` 和 `%LOCALAPPDATA%\CodexDeck`；
- Inno Setup `AppId` 与单实例 mutex。

用户界面、安装程序和发布文件使用 PanPal 名称。

PanPal 源自 `voltwake/cardputer-codex-deck`，与 OpenAI 无隶属关系。
